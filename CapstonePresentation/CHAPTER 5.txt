Recommendations
These are the things, according to the assessment, that are required to correct to get the. Diocese of Iligan site which is operational to everyone, not only administrators.
1. Correct Payment, citizens are unable to complete the process of donating as half of them do not use PayPal.
•	Add GCash and PayMaya what Filipinos actually use
•	Add bank transfer with clear instructions
•	Simplify the payment flow—no confusing redirects
•	Show security badges so users trust the process
2. Redesign the Booking some of the citizens can't figure out which dates are available.
•	Show availability with color-coded dates (green = available, gray = booked)
•	Add a "Next Available" button for quick booking
•	Make the calendar work better on phones with larger touch targets
•	Let users preview their booking before submitting
3. Simplify the Booking Form, too many required fields overwhelm users.
•	Cut required fields to essentials: name, contact, service, date/time
•	Hide optional fields under "Show More"
•	Pre-fill information for logged-in users
•	Show examples for each field ("Phone: 0917-123-4567")
•	Add a progress bar ("Step 2 of 3")
4. Some of the users feel confident using the system alone.
•	Add a 5-step tutorial for first-time users
•	Create short video guides (2-3 minutes) in Filipino and English
•	Put help buttons on every page
•	Add an FAQ section
•	Offer phone support during business hours
5. Optimize for Mobile (Moderate Priority - Score: 3.9) Most citizens use phones, not computers.
•	Build a Progressive Web App (PWA) that works like an app without downloads
•	Make it work offline for viewing bulletins
•	Optimize for touch with larger tap targets
•	Let users add it to their home screen
6. Add SMS Notifications (Moderate Priority) Not everyone checks email or app notifications.
•	Send SMS confirmations for bookings
•	Send reminders 24 hours before appointments
•	Send donation receipts via text
•	Let users choose their notification preferences
7. Add Filipino and Cebuano (Future Enhancement) Some parishioners prefer their local language.
•	Add language toggle for English, Filipino, and Cebuano
•	Save language preference for return visits
These aren't nice-to-haves they're essential to serving the 96% citizen majority. Fix the top four, and you'll transform the platform from "frustrating but functional" to "actually helpful." The technology is solid. Now make it accessible
